# 直播水族馆使用说明

> 当前说明适用于软件版本 1.5.0（多平台直播与智能音量版）。

## 1. 软件简介

直播水族馆是一款适用于 Windows 10/11 64 位系统的多平台直播监看工具，可在同一个窗口中查看多个公开的斗鱼、Bilibili 和抖音直播间。

- 最多可同时监控 16 个直播间。
- 房间列表的保存数量不受 16 路限制。
- 默认只播放一个直播间的声音，也可按住 Shift 选择多路音频并分别调节音量。
- 支持整体布局、单个画面尺寸、拖动排序、三平台实时文本弹幕、完整标题样式、开播与直播热度提醒、智能音量和诊断日志。
- 不需要登录斗鱼、Bilibili 或抖音账号，也不会保存平台账号、Cookie 或密码。

> 本软件仅支持无需登录即可访问的公开直播间。弹幕功能只接收和展示普通文本，不支持发送弹幕，也不展示礼物、醒目留言、舰长、进场和历史消息；软件不提供录制和云同步功能。

## 2. 安装与启动

### 2.1 系统要求

- Windows 10 或 Windows 11，64 位。
- 建议使用支持硬件视频解码的显卡，并保持显卡驱动为较新版本。
- 同时播放的房间越多，对 CPU、GPU、内存和网络带宽的要求越高。

### 2.2 安装

1. 双击安装程序 `直播水族馆-Setup-<版本>.exe`。
2. 按安装向导完成安装。默认安装到当前用户目录，不需要管理员权限。
3. 从桌面快捷方式或开始菜单启动“直播水族馆”。

## 3. 快速上手

### 第一步：把房间加入列表

1. 输入纯数字房间号时，先在窗口顶部选择“斗鱼”、“Bilibili”或“抖音”；也可以直接粘贴 Bilibili 或完整的抖音直播链接，软件会自动识别平台。
2. 输入房间号，例如 `123456`，或粘贴形如 `https://live.bilibili.com/6`、`https://live.douyin.com/475999770624` 的链接。
3. 点击“加入列表”，也可以直接按 `Enter` 键。
4. 软件查询并显示平台、主播、标题、开播状态和规范房间号；确认后房间会出现在左侧“房间列表”中。

裸数字房间号只在所选平台内查询，不会同时碰撞查询所有平台。加入列表仅用于保存房间，此时还不会创建播放器或占用一路监控位置。

### 第二步：开始监控

使用以下任一种方式，把左侧房间加入右侧监控区：

- 双击房间列表中的房间；
- 按住房间并拖到右侧监控区的指定位置。

加入后，软件会自动获取房间信息和直播线路。正在直播的房间将开始播放；未开播的房间会保留在监控区，并定期检查开播状态。

右上方的“在线 X/Y”表示：当前正常播放的房间数 / 当前监控的房间总数。

![添加房间并开始监控的三步图解](images/guide-02-quick-start.png)

### 第三步：选择声音

- 单击某个直播画面，即可把它设为当前唯一的音频来源。
- 按住 Shift 点击其他直播画面，可添加多个音频焦点；再次按住 Shift 点击已选画面可移除该路音频。
- 多音频模式下，每个焦点画面的工具栏会显示独立音量按钮；退出多音频模式后重新由全局音量控制。
- 当前音频画面会显示蓝色边框和“当前音频”提示。
- 点击顶部静音图标，可关闭所有当前声音。
- 拖动顶部音量滑块，可调节全局音量。

切换音频不会停止其他直播画面。当前音频房间会优先使用较高码率，其他房间通常使用较低码率，以减少资源占用。

如果不同直播间在相同滑块位置下听起来忽大忽小，可在“设置 → 播放设置”开启“智能音量均衡”。该功能默认关闭，会为每个房间独立、缓慢地校准基础响度；刚开始播放时需要数秒完成预热。多音频模式下，各房间的独立音量仍然有效，用于控制它们之间的相对大小。

![选择音频与多画面功能图解](images/guide-03-features.png)

### 第四步：调整画面布局

- 点击顶部“整体布局”，可选择 `3×3` 或 `4×4`，设置监控区域的基础网格。
- 单个画面的 `1×1`、`2×2`、`3×3`、`4×4` 是当前基础网格内的占格大小。例如在 `4×4` 布局下选择 `3×3` 会占 16 格中的 9 格；在 `3×3` 布局下选择 `2×2` 会占 9 格中的 4 格。
- 拖动大画面时可直接选择新的网格位置，松开后其余 `1×1` 小画面会自动重排；将小画面拖到大画面上仍会交换两个直播画面。
- 将鼠标移到直播画面上，拖动工具栏中的“⠿”按钮，可与其他画面交换位置。
- 点击单个画面工具栏中的“▦”，可单独设置该画面的尺寸。

还可以把画面拖到空白网格位置。窗口缩放后，画面会根据可用空间实时重排；如果剩余空间不足，某些尺寸操作会被拒绝，窗口顶部会显示提示。

| 加入列表 | 查询房间资料，确认后保存到左侧列表，但不立即开始播放 |
| 在线 X/Y | 显示正在播放数和当前监控总数 |
| 整体布局 | 选择 3×3 或 4×4 基础网格；单画面尺寸在当前网格内占格 |

### 4.2 左侧房间列表

房间列表用于长期保存常看的直播间，并显示平台徽标、房间号、标题、开播状态和是否正在监控。在线筛选与标题下方的平台筛选栏相互独立：在线筛选可切换“全部/在线”，平台筛选可切换“全部/斗鱼/Bilibili/抖音”，两者会同时生效。例如选择“在线”和“抖音”时，只显示正在直播的抖音房间。筛选只改变列表显示，不会停止已经开始的监控。

- 双击未监控的房间：开始监控。
- 拖动未监控的房间：放到右侧指定位置开始监控。
- 在“全部”视图中按住列表项并上下拖动：自定义房间列表顺序。其他筛选视图会禁用目录重排，但仍可把房间拖入右侧监控区。列表项下方显示平台直播标题，不受画面自定义标题影响。
- 点击房间右侧“✕”：从列表中永久删除。软件会先弹出确认窗口；如果该房间正在监控，确认删除后也会关闭对应画面。
- 拖动左右区域之间的分隔条：调整房间列表宽度。
- 点击顶部“☰”：折叠或展开房间列表。

“退出监控”和“永久删除”含义不同：退出监控只关闭播放器，房间仍保留在列表中；永久删除会把房间从列表中移除。

### 4.3 直播画面工具栏

将鼠标移到直播画面上，底部会显示工具栏。

| 按钮 | 用途 |
| --- | --- |
| ⠿ | 拖动画面并与其他画面交换位置 |
| ↻ | 刷新房间信息、开播状态和播放线路 |
| ▦ | 设置此画面的 1×1、2×2、3×3 或 4×4 尺寸 |
| 弹 | 开启或关闭此直播间的弹幕；智能策略开启时可临时覆盖当前策略 |
| 滑块图标 | 鼠标移入后调整此直播间的弹幕字体大小和透明度 |
| 字 | 编辑画面标题 |
| ✕ | 退出监控并让房间返回左侧列表 |

选择声音不在工具栏中操作，请直接单击直播画面。刷新房间不会改变现有顺序、画面尺寸、自定义标题或音频选择。

Bilibili 播放若持续出现数据包停顿或明显音频欠载，软件会在确认属于网络线路问题后，优先切换到同清晰度的其他 CDN；切换时画面可能短暂显示“正在重连”。单次极短波动和渲染性能问题不会触发换线，避免线路来回抖动。

斗鱼、Bilibili 和抖音直播间会共用上述弹幕开关与显示设置。Bilibili 与抖音弹幕使用无需登录的网页公开链路；抖音通过短周期读取最近评论并按消息 ID 去重，因此高流量房间在极端情况下可能漏掉少量消息。如果平台接口或风控策略变化，视频仍可正常播放，但弹幕可能暂时不可用，具体原因可在诊断日志中查看。

## 5. 编辑画面标题

1. 将鼠标移到需要修改的画面上。
2. 点击工具栏中的“字”。
3. 根据需要修改以下内容：
   - 标题文字；
   - 字号，范围为 10–72；
   - 从 Windows 已安装字体中选择标题字体；
   - 文字颜色，可直接使用取色板；
   - 背景颜色和透明度；完全透明时不显示背景；
   - 外描边的颜色和粗细；描边只向文字外侧扩展；
   - 左上、顶部居中、右上、左下、底部居中或右下锚点；
   - 水平 X 和垂直 Y 偏移。
4. 修改效果会实时显示在直播画面中。
5. 点击“完成”保存；点击“重置”可恢复为仅显示最新主播名称的默认标题。房间号仍可在左侧房间列表中查看。

标题背景带有小幅圆角。热度提示与标题使用防遮挡布局，避免两个标签覆盖在一起。

按 `Esc` 可取消当前标题编辑。如果当前没有打开标题编辑器，在主窗口按 `Esc` 会退出软件。

## 6. 弹幕显示与设置

点击顶部工具栏中的“弹”，可以打开“全局弹幕”面板。实时弹幕默认开启；关闭“显示实时弹幕”后，软件会停止所有房间的弹幕监听与显示。

全局弹幕面板提供以下设置：

- **智能弹幕策略**：根据当前音频焦点和热度热点自动决定哪些房间显示弹幕。该功能默认关闭。
  - **精简**：仅当前音频焦点房间显示，显示区域为画面高度的 35%。
  - **普通**：当前音频焦点房间显示；发生热度热点的房间可临时显示，显示区域为 60%。
  - **Max**：所有允许弹幕的监控房间都显示，显示区域为 100%。
- **显示区域**：智能策略关闭时，可在 30%–100% 之间设置弹幕占用的画面高度；智能策略开启时会随策略强度自动设为 35%、60% 或 100%。
- **字体大小**：设置所有房间的基础弹幕字号，可在 40%–160% 之间调整。
- **透明度**：设置所有房间的基础弹幕透明度，可在 10%–100% 之间调整。

每个直播画面也可以单独设置：

1. 将鼠标移到直播画面上，显示底部工具栏。
2. 点击“弹”可单独开启或关闭该房间弹幕。智能策略开启时，此操作会临时覆盖策略当前的显示决定。
3. 将鼠标移到“滑块”图标上，可调整该房间的字体大小和透明度；房间设置会在全局基础值上进一步缩放。

如果只有部分房间没有弹幕，请依次检查全局弹幕开关、该房间的弹幕开关以及智能策略当前级别。弹幕设置会自动保存。

## 7. 直播热度提醒与设置

点击窗口右上角“设置”，可以使用以下功能：

- **直播热度暴涨提醒**：默认开启。斗鱼使用贵宾人数，Bilibili 使用直播间当前观众人数；短时间明显上涨时显示橙色提示，并在热点持续期间保持橙色边框。Bilibili 的数据不是网页上的人气值或累计看过人数。
- **常驻显示房间数据**：默认关闭。开启后，从收到第一条数据起在监控画面显示当前数值，包括算法预热期；斗鱼显示“贵宾”，Bilibili 显示“观众”。关闭后仅在热度暴涨状态显示橙色提示。
- **智能音量均衡**：默认关闭。按直播间独立分析并平缓校准基础响度，减少切换直播间时的音量跳变；不会覆盖全局音量或多音频模式下的房间独立音量。
- **主播开播提醒**：默认开启。软件每 30 秒刷新一次房间状态；同一轮检测到多个主播开播时会合并成一次应用内提醒，避免连续弹出多个窗口。
- **后台时使用 Windows 系统通知**：默认关闭。开启后，软件位于后台或最小化时使用 Windows 通知；位于前台时仍显示应用内提醒。点击系统通知可返回软件。
- **每小时休息提醒**：默认开启。每累计观看一小时显示喝水或活动提示；关闭期间不会补发错过的提醒。
- **打开诊断日志**：打开诊断窗口，查看播放、网络、音频、性能采样和热度检测记录。
- **使用说明**：在默认浏览器中打开安装目录内的离线说明页，不需要联网。
- **更新日志**：查看各版本新增、优化与修复内容。
- **关于**：查看软件版本、作者及联系邮箱；点击“支持作者”可打开支付宝收款码。
- **软件更新**：软件启动后会在后台检查官方更新清单，也可点击“检查更新”手动检查。发现新版本时，设置按钮显示红点，点击“前往下载”会在浏览器中打开 Gitee 官方发行页；软件不会自动下载或安装。
- **软件版本**：显示当前安装的软件版本号。

关闭“直播热度暴涨提醒”会停止房间数据监听和影子策略统计，“常驻显示房间数据”也会暂时不可用。再次开启后，监听会自动恢复。

热度提示淡入显示；热点结束后的回落提示最多保留约 10 秒。首次全新安装并启动软件时，使用说明会自动打开一次，后续启动不会重复打开。

## 8. 刷新、离线与自动恢复

- 房间显示“未开播”时，会继续保留在监控区并定期检查状态，无需反复添加。
- 播放中断时，软件会尝试备用线路、较低码率并自动重试。
- 如果主播已开播但软件仍显示离线，可点击该画面的“↻”重新获取状态和播放线路。
- 如果多个有效房间同时提示“暂时无法获取直播源”，可能是网络、对应平台页面或接口发生变化，重新安装软件通常无法解决，需要更新软件版本。

## 9. 查看诊断日志

当右上角“设置”按钮出现数字角标，表示软件记录了新的警告或错误。

1. 点击“设置”，再点击“打开诊断日志”。
2. 可按严重程度、分类或房间号筛选事件。
3. 选中事件后，下方会显示详细信息。
4. “Copy selected”复制当前事件，“Copy summary”复制诊断摘要。
5. “Open logs”打开本地日志目录，“Clear view”仅清空当前窗口中的可见记录。

提交问题时，建议提供问题发生时间、房间号、Windows 版本、CPU/GPU、软件版本，以及对应时间段的日志。发送日志前请先人工检查是否含有个人信息。

## 10. 自动保存的设置

软件关闭后会自动保存并在下次启动时恢复以下内容：

- 房间列表及其顺序；
- 当前监控的房间及画面顺序；
- 全局音量和静音状态；
- 窗口位置和大小；
- 左侧栏宽度及折叠状态；
- 整体布局及单画面尺寸；
- 自定义标题、字体、字号、文字颜色、背景、外描边和位置；
- 全局弹幕开关、智能策略、显示区域、字号和透明度；
- 各房间的弹幕开关、字号和透明度；
- 直播热度提醒与房间数据常驻显示选项；
- 智能音量均衡、主播开播提醒、Windows 系统通知和每小时休息提醒选项。

相关文件位于：

- 设置：`%LocalAppData%\DouyuMonitor\settings.json`
- 日志：`%LocalAppData%\DouyuMonitor\logs\monitor-YYYYMMDD.log`

卸载软件不会自动删除上述用户数据。如需彻底清理，可在卸载后手动删除 `%LocalAppData%\DouyuMonitor` 文件夹。

## 11. 常见问题

### 房间无法加入列表

输入纯数字房间号时确认选择了正确平台；粘贴直播链接时确认来自 `live.bilibili.com` 或 `live.douyin.com`。房间必须存在且可公开访问，重复房间不会再次加入。

### 画面黑屏但有状态或声音

先退出该房间的监控，再从左侧列表重新加入；同时更新显卡驱动，并关闭可能覆盖或注入画面的录屏、叠加层、远程桌面软件。

### CPU、GPU、内存或网络占用过高

减少同时监控的房间数量，确认硬件视频解码正常工作，并尽量使用稳定的有线网络。即使某个房间不是当前音频或主画面，只要它仍在监控，就会继续消耗资源。

### 看不到弹幕或只有部分房间显示弹幕

斗鱼、Bilibili 和抖音房间都支持普通文本弹幕。请先确认顶部“弹”面板中的“显示实时弹幕”已经开启，再检查对应画面工具栏中的房间弹幕开关。如果启用了智能弹幕策略，精简和普通级别会主动隐藏部分非音频焦点房间的弹幕；需要全部显示时可选择 Max，或关闭智能策略后手动设置显示区域。Bilibili 与抖音弹幕使用无需登录的网页公开链路，平台接口或风控变化时可能暂时不可用，可在诊断日志中查看原因。

### 智能音量为什么不会立刻把声音调成一样大

智能音量会使用数秒的分析窗口并限制调节速度，避免主播说话停顿、游戏音效或短促爆音导致音量频繁起伏。它校准的是每个房间的基础响度，不会让所有瞬间都完全一致。如果某个房间本身动态范围很大，或你更希望保留原始音量，可在“设置 → 播放设置”关闭该功能。

### 软件重启后配置异常

先退出软件，备份 `%LocalAppData%\DouyuMonitor` 文件夹，再将 `settings.json` 移出该目录后重新启动。软件会生成新的默认配置。

更多排查方法请参阅[故障排除](troubleshooting.md)。
